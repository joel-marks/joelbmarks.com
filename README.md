# joelbmarks.com

Personal site of Joel B. Marks. Built with Hugo and PaperMod.

## Run locally

```sh
git clone --recurse-submodules git@github.com:joel-marks/joelbmarks.com.git
cd joelbmarks.com
hugo server
```

Site available at http://localhost:1313

## Stack

- Hugo (extended)
- PaperMod theme (`themes/PaperMod`, git submodule)
- Vanilla CSS, custom overrides in `assets/css/extended/`
